# projeto-phishing-para-facebook
projeto criado para capturar usuario e senha da pagina do facebook

### Ferramentas
 kali linux  
 setoolkit


 ###  Configurando o Phishing no Kali Linux  

 -Acesso ao Root ```sudo su ```
 -Inicia o Setoolkit ``` setoolkit ```
 -Escolha de tipo de ataque ```Social-Engineering Attacks```
 -Vetor de ataque ```Web Site Attack Vectors ```
 -Metodo de ataque ```Credential Harvester Attack Method```
 -Sub metodo de ataque ``` Site Cloner ```
